# 第170轮仿真失稳：定位与修复

## 复现证据

用户正式运行在显示第170轮后出现 QACC→QVEL/QPOS→控制量 NaN/Inf，程序按有限值检查退出。此前64轮短测未覆盖该问题，1ms时步本身不能解决它。

以保留下来的 `model_100.pt` 冻结策略，对512环境反复进行完整随机重置，在第12批、第312号环境重现同类故障，耗时约9秒。保存重置后的完整状态、实际材质/惯性参数、每物理步控制与外力后，独立MuJoCo单环境97步回放与原生批量仿真发布的qpos/qvel逐元素一致。原正式运行没有故障帧快照，因此这里复现的是同类故障，不宣称找回了第170轮的原始轨迹。

| 证据 | 结果 |
|---|---|
| 初始最深地形穿透 | 8.424cm，前右轮；膝部也约5.06cm |
| 初始根部实际离地高度 | .519m；世界坐标z=.0655并非只离地6.5cm |
| 第93步最大关节速度 | 约1.35×10⁶rad/s |
| 首次QACC警告 | .093s |
| QPOS/QVEL警告 | .095s |
| 第97步最大double速度 | 约1.57×10⁴⁸，转float32溢出为Inf |
| 最小复放 | 保存第82步完整积分状态后，仅需15步；该时刻已无接触，机身被抛起到离地约1.81m |

## 原因与单变量对照

随机根部姿态直接叠加固定出生高度，会让M1某些碰撞几何穿进楼梯。原恢复系数映射使用 `solref=[.02,ζ]`；MuJoCo接触刚度与 `1/(timeconst×ζ)²` 成正比，因此减小ζ同时无意增大了刚度，捕获样例最多约21.2倍。深穿透被很硬的接触弹簧推出，产生高速旋转；`implicitfast` 对耦合多刚体旋转省略部分速度导数，后续即使离地也可能继续数值增能。[MuJoCo接触参数公式](https://mujoco.readthedocs.io/en/3.11.0/modeling.html#reference)、[积分器说明](https://mujoco.readthedocs.io/en/3.11.0/computation/index.html#numerical-integration)。

以下每组只改一个变量，保持同一记录的其余状态与输入：

| 对照 | 97步结果 |
|---|---|
| 原设置 | 发散 |
| 控制力矩全部为0 | 仍发散，且更早；因此不是PPO输出NaN才导致仿真崩溃 |
| 外力/外扭矩全部为0 | 仍发散 |
| 关闭地形接触 | 稳定 |
| 初始机身抬高15cm | 稳定 |
| 仅换完整implicit积分器 | 稳定，即使仍用原来的高刚度材质 |
| 仅把接触设成临界阻尼 | 稳定，但会损失原要求的恢复系数随机化，未作为最终方案 |
| 保留ζ，仅令timeconst=.02/ζ | 稳定；最大速度约226rad/s，无BADQACC/QVEL/QPOS警告 |

## 最终修复

1. 完整训练配置改为 `implicit`，保留1ms物理步、20ms策略步。basic旧配置继续使用原积分器。
2. 材质改成 `solref=[.02/ζ,ζ]`，使 `timeconst×ζ=.02` 恒定；保留原恢复系数采样0–.5及64桶，不再同时放大接触刚度。它依然是MuJoCo近似映射，不是实测恢复系数。
3. 重置时用M1默认关节姿态下全部55个碰撞几何的包围球，以及实际地形高度场足迹内全部网格顶点，计算最低安全根部高度。仅在需要时抬升Z，保留XY、完整随机朝向、线/角速度和原RNG采样序列；安全间隙5mm。

没有改M1的标称质量、惯量、几何、kp/kd基准、力矩上限，也没有删除奖励或关闭摩擦、质量、增益、延迟、外力和推扰随机化。数值有限值检查和禁止仿真内部自动重置仍保留，没有用NaN截断把失败当正常样本。

# M1 第10000号权重评测

训练持续运行，本评测使用独立CPU进程与冻结权重，不更新模型、不暂停训练。
视频恢复了用户原始URDF的17个外观网格。每段固定展示第0个环境，没有挑选成功样本；
原速25fps，达标或失败后只保留1秒定格，未达标的片段保留完整20秒。
视频中的“已暂停”仅指评测画面定格，后台训练从未暂停。

[播放汇总视频](M1_10000_terrain_evaluation.mp4)

## 条件与边界

- 标称M1质量、惯量和电机增益，libccd碰撞器、1ms物理步；指令vx=0.5m/s、vy=0、yaw rate=0。
- 关闭评测实例的质量/材质/增益随机化、噪声、延迟和外力，训练中的随机化继续保持启用。
- 每条件8个初始XY小偏移（±0.1m），直立初始化，固定seed123。不是跨随机种子的统计鲁棒性验证。
- 成功标准：20秒内前进4m，期间倾斜不超过0.8rad（约46°），不触发其他终止。达到目标后停止计分。
- 低/中/高等级0/2/4分别取训练难度区间中点0.1/0.5/0.9。
  坡度约2.0°/9.9°/17.5°；台阶约4.3/9.5/14.7cm（高度场5mm量化）。
  平地和±4cm粗糙地面的定义不随等级变化，重复行不代表新的难度。
- 通过4m测试不代表速度跟踪准确，也不能据此断言实机可用或训练已收敛。
